# 선택적 결과 카드

**문제와 적용 범위:**
**현재 결론 / 상태:**
**작동 모델:**
**다른 표현에서 새로 드러난 점:** 해당할 때만 기록한다.
**수행한 검사:** 입력, 방법, 결과, 증거 위치. 계획과 실행을 분리한다.
**핵심 가정·근사·미지:** 결론을 흔드는 항목만 기록한다.
**경쟁 설명과 판별 조건:** 필요할 때만 기록한다.
**수정 또는 유지:** 무엇이 왜 바뀌었거나 유지되었는가?
**다음 행동 / 중단 조건:**

빈 양식을 모두 출력하지 않는다. 작성 자체는 사고 행동이나 검증의 증거가 아니다.
